# Hardware Implementation & Synthesis Reports (`fpga_implementation/reports/`)

This directory archives all synthesis, place-and-route, timing closure, power estimation, and resource utilization reports generated by the AMD Vivado Design Suite for the Spartan-7 FPGA target (`XC7S50-1CSGA324C`).

## Planned Report Catalog (Milestones M2 & M3)

1. **`utilization_placed.rpt` & `utilization_routed.rpt`**:
   - Detailed breakdown of Configurable Logic Block (CLB) LUTs, Slice Registers (FFs), DSP48E1 slices, and Block RAM (RAMB36E1/RAMB18E1) consumption.
   - Compares actual synthesis metrics against projected architectural budgets (<3,500 LUTs, 17 DSPs, 2.5 BRAMs).

2. **`timing_summary.rpt`**:
   - Worst Negative Slack (WNS), Total Negative Slack (TNS), Worst Hold Slack (WHS), and clock skew reports for the 100.0 MHz master clock domain.

3. **`power_analysis.rpt`**:
   - Vivado Report Power estimates for static vs dynamic power consumption at 100 MHz clock rate and 250 Hz sample strobe (<30 mW projected dynamic power).
